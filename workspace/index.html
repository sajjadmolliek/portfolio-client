Downly

A public Instagram media downloader, in 13 languages

A production Instagram downloader for public reels, posts, stories and carousels—media is extracted server-side through a swappable provider chain, and the browser only ever receives signed, expiring, same-origin links, so a raw CDN URL never reaches the client.

Key Highlights

Public reels, posts, IGTV, stories and carousels, downloaded in original quality.

Real file downloads via a signed, expiring, same-origin streaming proxy.

In-browser MP3 extraction and carousel ZIP bundling, with no server-side transcoding.

Swappable extraction: providers tried in priority order, replaceable without touching the API or UI.

13 locales with right-to-left Arabic, every language tree pre-rendered at build time.

Installable PWA with an OS share target — share a reel straight from Instagram into Downly.

Glasswind

A glassmorphism React component library on npm

A glassmorphism React component library published on npm—21 accessible, GPU-animated frosted-glass components (buttons, modals, forms, overlays) plus hooks, shipped as a zero-runtime-dependency, tree-shakeable package for any React or Next.js app.

Key Highlights

21 accessible frosted-glass components + 6 hooks, themeable via CSS variables.

Zero runtime dependencies; tree-shakeable ESM + CJS build with full TypeScript types.

GPU-only (transform/opacity) 60fps animations with dark mode & reduced-motion.

SSR-safe for Next.js; plain CSS, no Tailwind required.

Live on npm — install with npm install glasswind.
